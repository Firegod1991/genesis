# Credits

Genesis is a catalog and a set of tools. Everything it carries was made by other people. Thank them, and support them while the internet still works.

## Projects that shaped it

* [Project NOMAD](https://github.com/Crosstalk-Solutions/project-nomad) by Crosstalk Solutions: the model for an offline knowledge and AI server with a command center.
* [Offgrid Tools](https://github.com/psyb0t/offgrid-tools) by psyb0t: the idea of carrying apps, operating system images and saved container images along with the knowledge.
* [EmComm Tools OS Community](https://github.com/thetechprepper/emcomm-tools-os-community) by The Tech Prepper: the reference for what a field radio station needs.
* [Doomsday Cyberdeck](https://github.com/EzioDEVio/Doomsday-Cyberdeck) by EzioDEVio: the field hardware layout.
* [Internet in a Box](https://internet-in-a-box.org): two decades of proving that offline libraries change lives.

No code or text from these projects is included here.

## Software Genesis runs or ships

Kiwix, Ollama, Open WebUI, LibreTranslate, CyberChef, IT Tools, FlatNotes, Stirling PDF, Homebox, Kolibri, Calibre Web, Jellyfin, DevDocs, code-server, Gitea, Ergo, The Lounge, Mumble, Meshtastic, MeshCore, Reticulum, OpenWebRX+, readsb, tar1090, AIS-catcher, Valhalla, File Browser, osmium, and every project listed in the [catalog](docs/CATALOG.md).

The dashboard includes [MapLibre GL JS](https://maplibre.org) (BSD 3 Clause), [PMTiles](https://github.com/protomaps/PMTiles) (BSD 3 Clause), map styles generated with [Protomaps basemaps](https://github.com/protomaps/basemaps) (BSD 3 Clause) and the [Overpass](https://overpassfont.org) typeface (SIL Open Font License). Their license texts are in `dashboard/static/vendor/`.

The QR code a phone's camera opens Genesis with is drawn by Project Nayuki's [QR Code generator library](https://www.nayuki.io/page/qr-code-generator-library) (MIT), carried as `genesis/qrcodegen.py` with its license at the top. The Windows download carries the embeddable [Python](https://www.python.org) from python.org, under the Python Software Foundation License, whose text is in its `python` folder.
